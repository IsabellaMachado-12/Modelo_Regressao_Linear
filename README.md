# 🏠 Previsão de Preços de Imóveis com Regressão Linear

Projeto desenvolvido para estudos de **Machine Learning** utilizando **Python** e **Scikit-learn**. O objetivo é prever o preço de um imóvel com base em sua área (m²) por meio de um modelo de **Regressão Linear**.

## 🚀 Funcionalidades

* Criação de uma base de dados para treinamento.
* Visualização dos dados em gráfico de dispersão.
* Treinamento de um modelo de Regressão Linear.
* Previsão do preço de um imóvel a partir de sua metragem.

## 🛠️ Tecnologias

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

## 📦 Instalação

```bash
pip install pandas scikit-learn matplotlib
```

## ▶️ Como Executar

1. Clone o repositório.
2. Instale as dependências.
3. Abra o notebook `Regresao_imoveis.ipynb` no Google Colab ou Jupyter Notebook.
4. Execute todas as células para treinar o modelo e realizar as previsões.
